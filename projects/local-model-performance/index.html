Cloud vs. Local LLM Agents for Generating Lecture Slides with an Agent Skill

October 2026 A preliminary cost–time–quality study Hisham Abuella اقرا بالعربي

Three cloud models (Claude Opus 5.5, Sonnet 5.5 and Haiku 5.5) and one local model (qwen3.8 27B through Ollama on a Mac Studio, M4 Max, 64 GB) built the same 20–30 slide lecture deck from the same prompt, with the present-in-html Agent Skill in Claude Code. Opus and Sonnet scored 9/10 on both subjects, and Sonnet took about half Opus's time at a quarter to a third of its cost; Haiku scored 7/10 at about $0.30. The local dense model did not finish within 120 minutes.

Read the article IEEE paper (two-column)

A preliminary study. Each model ran once per task, so these are early indications, not firm conclusions. More tests are needed.

The Study, in Short

Each model got one course module and one fixed prompt: turn it into a 20–30 slide deck for a 50-minute lecture, with speaker notes on every slide and a quiz at the end. There were two subjects, Wireless 101 and STATS 101. The skill's checker and a blind LLM judge scored every finished deck.

Generated Decks: the Main Comparison

One run per model per subject. Each deck is one HTML file and opens in a new tab.

Wireless 101

  • Opus 5.530 slides · judge 9/10 · 11m 44s · $2.88
  • Sonnet 5.530 slides · judge 9/10 · 5m 27s · $0.90
  • Haiku 5.529 slides · judge 7/10 · 7m 05s · $0.24

qwen3.8 27B, the local model, reached the 120-minute limit on Wireless 101 without writing any slides, so there is no deck.

The decks marked “Assembled afterwards” were not made by the models. I put them together after the runs from the slide files the unfinished local runs left, so their slides can be seen. They were not checked or judged, and they are not counted in any result.
