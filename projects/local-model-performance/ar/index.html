المظهر

LLM agents على الـ cloud ولا محلية، لعمل slides المحاضرات بـ Agent Skill

أكتوبر 2026 دراسة مبدئية عن التكلفة والوقت والجودة هشام أبو العلا Read in English

تلات models على الـ cloud، هما Claude Opus 5.5 وSonnet 5.5 وHaiku 5.5، وmodel محلي واحد، qwen3.8 27B، شغال بـ Ollama على Mac Studio فيه M4 Max وذاكرة 64 GB، عملوا نفس عرض المحاضرة، من 20 لـ 30 slide، من نفس الـ prompt، بالـ Agent Skill بتاعة present-in-html في Claude Code. Opus وSonnet خدوا 9/10 في الموضوعين، وSonnet خلّص في حوالي نص وقت Opus، بربع لتلت تكلفته؛ وHaiku خد 7/10 بحوالي 0.30 دولار. والـ model المحلي الـ dense ماخلصش في 120 دقيقة.

اقرا المقال الـ IEEE paper (عمودين)

دراسة مبدئية. كل model اشتغل مرة واحدة بس في كل مهمة، فدي مؤشرات أولية، مش نتايج نهائية. لسه محتاجين tests أكتر.

الدراسة باختصار

كل model خد module واحد من كورس وprompt ثابت: يحوّله لعرض من 20 لـ 30 slide لمحاضرة 50 دقيقة، فيه speaker notes على كل slide وquiz في الآخر. كان فيه موضوعين، Wireless 101 وSTATS 101. الـ checker بتاع الـ skill وLLM judge مايعرفش مين عمل إيه (blind) قيّموا كل عرض خلص.

العروض اللي اتعملت: المقارنة الأساسية

run واحد لكل model في كل موضوع. كل عرض ملف HTML واحد، وبيفتح في tab جديدة.

العروض اللي اتعملت: تجربة الخطة

تجربة منفصلة، ومش بتتقارن بالـ runs اللي فوق. Opus كتب خطة واحدة لـ STATS 101، وتلات models محلية بنوا منها عرض.

  • qwen3.6 35B-A3B، MoE محلي30 slide · التقييم 9/10 · 20 دقيقة
  • اتجمّع بعدينqwen3.8 27B، محليوقف بسبب API error. فيه 10 slides من الـ run اللي ماخلصش. ماتقيّمش.
  • اتجمّع بعدينgemma4 26B، محليوقف بدري. فيه 10 slides من الـ run اللي ماخلصش. ماتقيّمش.

العروض اللي عليها «اتجمّع بعدين» مش الـ models اللي عملتها. أنا جمّعتها بعد الـ runs من ملفات الـ slides اللي سابتها الـ runs المحلية اللي ماخلصتش، عشان تقدر تشوف الـ slides بتاعتها. ماعدّتش على الـ checker ولا اتقيّمت، ومش محسوبة في أي نتيجة.
