What's in every book

Read to meEvery page narrated — English in Baba's own voice, Arabic alongside it. Auto-plays as the pages turn.
Two sets of artworkHand-drawn flat shapes for a newborn, or generated illustrations for later. One switch in the top bar.
Hear the soundA separate clip per animal, so the moo or the meow can be repeated as many times as he wants.
Full screenThe artwork fills the display, which is how it should be held in front of a baby.
His name in itA field on the cover puts any child's name into the dedication and the last goodnight.
Notes for grown-upsOne line per page on what a baby's eyes are doing, and how to read it aloud.

How they're made

Each book is a single HTML file plus a folder of audio — no framework, no build step, nothing to install. They work offline once loaded and will still open in ten years.

The artwork is hand-written SVG: a zebra is a white head, five black wedges and two eyes. The second set was drawn by image models running locally on a Mac Studio. The narration is ElevenLabs v4, with delivery written into the script as audio tags — [warmly] to open a page, [whispers] for the goodnight.

Everything regenerates from the transcripts in source/, so a story can be re-cut in a different voice, or a new one added, without touching the pages.
