How the skill works

From a plain sentence to a checked deck

  1. Ask

    I say what the talk is.

  2. Choose

    Claude picks the look.

  3. Write

    One section per slide.

  4. Check

    A script finds the problems.

  5. Deliver

    I get the file.

Five steps, one click each. Ask: the skill only asks what it cannot know, which is who the audience is and which real numbers to show. Choose: it matches the request to a recipe, for example tech talk goes to the studio theme, which is what this deck uses. Write: plain HTML, one section per slide, speaker notes on every slide. Check: a Playwright script opens the deck, looks at every slide and lists problems; Claude fixes them and runs it again, at most three passes. Deliver: the file path and the keys.

safe area

Stage: 1920 × 1080

Your window changes. The stage does not.

Resize your window and watch this line.

Every slide is drawn on a fixed 16:9 stage, 1920 by 1080 pixels, and the whole stage is scaled to fit your window, with letterbox bars if the shape differs. That is why text never reflows differently on a projector. The dashed outline is the safe area: 120 pixels on the sides, 96 top and bottom. Nothing important may leave it, and the checker enforces that. Try dragging your window narrower and read the percentage.

Try it: type below

This headline fits itself.

Type size: normal.

Type anything in the box. Each time you stop typing, the page calls the engine's refit function, and the engine shrinks the headline until it sits inside the safe area, or grows it when there is room, up to one and a half times for statements. The line underneath reads the size the engine chose. This is why the skill never tunes CSS to make text fit: if a slide is still too full at the smallest size, the checker tells you to cut words. Press Enter or Escape in the box to give the arrow keys back to the deck.

Click through slowly. There are six kinds of build, each with one job. Fade and rise bring a point in. Scale is for the one thing that should pop. Draw makes a line trace itself, which is perfect for a trend or an arrow. Count lands a number from zero. List reveals a list one item per click, which is why it takes three clicks. The rule from the skill: a build must reveal the next point in order. If it does not, delete it.

Magic Move, part one

Give two shapes the same name.

Idea Draft Deck

Magic Move is the Keynote trick: an object on one slide glides into the same object on the next. Here the whole recipe is one attribute. Each chip has data-magic with a name: m1, m2, m3. On the next slide three elements carry the same names. Click next and watch the engine measure both, then animate position, size and colour between them. Everything that is not paired just fades.

Magic Move, part two

The engine does the gliding.

IdeaDraft
Deck

Same three names, new places. Two chips stacked, and the third has become a huge word in a different typeface. When the typeface differs the engine cross-fades while the word travels, so there is no jump. Use it when the same object matters on two slides: a number that grows into the hero, a sentence that becomes a label. It does not morph one drawing into a different drawing; it moves the matching pieces. Press the left arrow to watch it run backwards.

Charts

A chart is one attribute

Change a number. The bars redraw.

The chart on the right is a figure with data-chart equal to column and data-values equal to Mon:3,Tue:5 and so on. That is the whole chart; there is no chart library. The four boxes rewrite data-values, move the highlight to the tallest bar, and ask the engine to redraw. Column, bar and line charts are built in, up to three series, and every chart also writes a hidden table so screen readers can read the data. The numbers here are made up for the demo; in a real deck the source goes in the caption.

Themes

22 themes, one tap each

Core

Library (16)

Tap a theme and the whole deck, including the rest of the slides, changes look. A theme is one block of colour, type and shape tokens; the layouts never hard-code a colour, which is how one switch can restyle everything. Six are core looks, for example Swiss and Editorial. Sixteen are made for professions: engineer, teacher, doctor, lawyer, founder and so on. The page reads the list from the engine, so it always shows what the file really has. The skill picked Studio for this deck because it is for talks and teaching. Tap Back to Studio when you are done.

Fonts

25 font pairings, same words, new voice

Core

Library

Fonts are a separate switch from themes, so you can pair any of the twenty-five with any theme. Tap one and this very headline changes. Theme default goes back to the theme's own pairing. Fonts load from Google Fonts the first time you pick them, so there can be a short pause; offline, the engine uses the system fallback listed in each stack. For a fully offline deck the skill can set data-fonts to system.

Marker

Press M and draw on this slide.

H highlighter L laser pointer E eraser Ctrl/Cmd+Z undo
scribble on me

The marker lets you draw on any slide while you present: press M, then drag with the mouse, a pen or your finger. H switches to a highlighter, E to the eraser, C clears the slide, one to four pick red, yellow, blue or white, and Control or Command plus Z undoes the last stroke. L is a separate laser pointer that leaves no trace. Drawings are kept per slide, shown in the presenter window and never printed. Go ahead: press M and scribble on the arrow.

Presenter view

Press P: a second window, just for you

Press P and the deck opens a presenter window: the current slide, a preview of the next build, your notes in large type, a timer and a clock. It talks to the audience window, so every key works in either one, and if the audience window is reloaded it reconnects. Allow pop-ups for this to work. Set data-duration on the deck and the timer becomes a countdown that turns amber for the last two minutes. Every slide in this deck has notes, so you can try it now.

The checker

The checker finds what you stopped seeing

$ node check.mjs broken.html

FAIL broken.html: 4 slides, 4 issues (0.8s)

slide 3: img "missing.jpg" has no alt attribute

fix: add alt="what it shows" (alt="" if purely decorative)

slide 4: ul has 7 bullets (max 6)

fix: cut to 5 or split into two slides

$ node check.mjs fixed.html --themes

ok fixed.html [keynote-white]: 4 slides, 0 issues (0.6s)

ok fixed.html [studio]: 4 slides, 0 issues (2.6s)

... and 20 more themes, all ok

This is real output. I made a small deck on purpose with two mistakes, a picture with no alt text and a list of seven bullets, and ran the checker on it. Then I fixed the deck and ran it across every theme, because someone will press S. Some lines are trimmed to fit the slide; the numbers and messages are as printed. The checker also catches overflow, text under 28 pixels, contrast under 4.5 to 1 and console errors. Rule from the skill: three passes at most, then cut words instead of tuning CSS.

Each button sends the same key the keyboard would, so you can try the whole toolbox: G for the overview, O for the outline with every slide listed, S for the theme and font panel, M for the marker, P for the presenter window, B for a black screen, F for fullscreen.
