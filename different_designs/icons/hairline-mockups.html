How to use the style here

  • One idea per figure. A figure stands for the place it opens (a station, a track section, an article). Never use one as decoration only.
  • Plate equals background. Set --hairline-plate to the card it sits on, or the plates show as boxes.
  • Lit lines take the page accent. --hairline-hi is the track colour; edge/mid/lo come from the page's grey tokens, in light and dark.
  • Quiet by default. No play; figures move only under the pointer or focus. Reduced motion is honoured by the library.
  • Arabic. Pass a translated label (from the page's Arabic block); the drawings themselves have no text, so they work in RTL as they are.
  • No CDN on the live site. Vendor the ESM file into js/vendor/hairline.js and bump its ?v= like the other shared scripts.
  • Own figures. The library's /hairline-create skill can draw site-specific ones (a 5G tower, the tuner dial, a mini radio) in the same rules.
